# Museum of the Year 3000

A single-line museum label, written in the deadpan voice of a curator from the year 3000, for one ordinary object from today. The label reimagines the object completely: what a future museum confidently believes it was for, based on nothing but how it looks and what people did around it.

`main.py` writes the label to `/output/entry.txt`.
